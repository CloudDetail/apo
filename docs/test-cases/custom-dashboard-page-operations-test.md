# 我的大盘页面操作测试文档

## 1. 测试范围

本文覆盖 APO「我的大盘」页面的页面操作测试，包含：

- 大盘列表页：`/custom-dashboard`
- 大盘查看页：`/custom-dashboard/:id`
- 大盘编辑页：`/custom-dashboard/:id/edit`

不覆盖系统内置 Grafana iframe 大盘、MySQL 大盘、后端单元测试和接口压测。

## 2. 测试目标

1. 验证用户能按权限查看、新建、复制、编辑、删除自定义大盘。
2. 验证查看页能按数据组、全局时间范围和大盘变量刷新组件数据。
3. 验证编辑页能配置大盘信息、变量、组件、查询、图表展示和布局，并能保存生效。
4. 验证无权限、无数据、查询失败、大盘不存在等状态有明确反馈。
5. 验证浅色/深色主题和常见桌面分辨率下页面无明显遮挡、错位和不可操作问题。

## 3. 前置条件

| 条件 | 说明 |
|---|---|
| 测试账号 | 至少准备 3 类账号：大盘创建者、仅查看用户、无创建/无编辑权限用户。 |
| 数据权限 | 至少准备 1 个有指标数据的数据组，以及 1 个无相关指标或无权限的数据组。 |
| 菜单权限 | 测试账号需要按用例分别配置「我的大盘」菜单、创建、查看、编辑、删除权限。 |
| 测试数据 | 至少准备 1 个包含折线图、面积图、柱状图、表格、指标卡、条形仪表组件的大盘。 |
| 浏览器 | Chrome 或 Edge 最新稳定版，建议同时验证 1366x768、1440x900、1920x1080。 |

## 4. 测试数据建议

| 数据 | 建议配置 |
|---|---|
| 大盘 A | 创建者私有大盘，包含自定义 PromQL 组件和内置资源变量。 |
| 大盘 B | 所有人可见大盘，包含多个图表组件和表格组件。 |
| 大盘 C | 团队可见大盘，只授权给指定团队。 |
| 查询表达式 | 至少包含 `cluster`、`namespace`、`svc_name`、`pod`、`instance_name` 中的一类标签。 |
| 异常查询 | 准备语法错误、无数据、结果过大或无权限的查询，用于验证异常态。 |

## 5. 列表页测试

| 编号 | 操作 | 预期结果 |
|---|---|---|
| CD-L-01 | 登录后点击左侧菜单「我的大盘」。 | 进入 `/custom-dashboard`，展示当前用户有权限查看的大盘列表。 |
| CD-L-02 | 查看列表字段。 | 展示名称、描述、创建者、可见范围、更新时间、操作；长描述悬停可查看完整内容。 |
| CD-L-03 | 在搜索框输入关键字并回车搜索。 | 列表只展示匹配关键字的大盘；清空搜索后可恢复全量列表。 |
| CD-L-04 | 有创建权限用户点击「新建」。 | 创建空白大盘，刷新权限菜单后跳转到 `/custom-dashboard/{id}/edit`。 |
| CD-L-05 | 无创建权限用户进入列表页。 | 不显示「新建」按钮；不可执行复制操作。 |
| CD-L-06 | 点击大盘名称或查看图标。 | 跳转到 `/custom-dashboard/{id}`，打开大盘查看页。 |
| CD-L-07 | 创建者点击编辑图标。 | 跳转到 `/custom-dashboard/{id}/edit`，进入编辑页。 |
| CD-L-08 | 非创建者查看同一个大盘。 | 可以查看时不显示编辑、删除入口，或进入编辑地址后提示无编辑权限。 |
| CD-L-09 | 有复制权限且有创建权限用户点击复制图标。 | 生成新大盘副本，当前用户成为新大盘创建者，并跳转到副本编辑页。 |
| CD-L-10 | 创建者点击删除图标后取消确认。 | 弹出删除确认框；取消后大盘仍保留在列表中。 |
| CD-L-11 | 创建者确认删除大盘。 | 大盘从列表消失；直接打开原查看地址显示大盘不存在或无可访问状态。 |

## 6. 查看页测试

| 编号 | 操作 | 预期结果 |
|---|---|---|
| CD-V-01 | 打开有权限的大盘查看页。 | 页面展示大盘标题、变量筛选区和组件网格；不使用 Grafana iframe。 |
| CD-V-02 | 创建者打开查看页。 | 顶部显示编辑按钮；点击后进入编辑页。 |
| CD-V-03 | 非创建者打开可见大盘。 | 可以查看组件数据；不显示编辑入口。 |
| CD-V-04 | 切换系统数据组。 | 变量候选值和组件数据按新数据组刷新，数据不越权。 |
| CD-V-05 | 切换系统全局时间范围。 | 所有组件按新的时间范围重新查询，刷新中组件显示加载或刷新状态。 |
| CD-V-06 | 操作内置资源变量，如集群、命名空间、服务、pod、实例。 | 变量支持清空、单选或多选；组件查询使用当前变量值刷新。 |
| CD-V-07 | 操作自定义 Label 变量。 | 变量候选值来自当前查询和权限范围；选择后组件数据刷新。 |
| CD-V-08 | 多选变量下拉框保持打开时连续勾选多个值。 | 不应在每次勾选时造成明显卡顿；关闭下拉后按最终选择刷新。 |
| CD-V-09 | 查看折线图、面积图、柱状图。 | 图表正常渲染，Tooltip、图例、坐标轴和阈值线可读，无遮挡。 |
| CD-V-10 | 图表返回序列较多时调整 Top N 展示数量。 | Top 50、100、200、500 等选项生效，页面不明显卡顿。 |
| CD-V-11 | 查看表格组件。 | 表头、行数据、数值列正常展示；超过分页阈值时分页可用。 |
| CD-V-12 | 查看指标卡和条形仪表组件。 | 数值、单位、小数位和阈值颜色符合配置。 |
| CD-V-13 | 滚动包含大量组件的大盘。 | 进入可视区域的组件能够加载；未进入可视区域的组件可显示等待加载状态。 |
| CD-V-14 | 查询返回无数据。 | 组件显示「无数据」状态，不出现空白块或控制台错误。 |
| CD-V-15 | 查询语法错误、超时、结果过大、指标不存在或无权限。 | 组件展示对应错误类型、原因提示和「重试」入口。 |
| CD-V-16 | 点击异常组件的「重试」。 | 使用当前数据组、时间范围和变量重新查询该组件。 |
| CD-V-17 | 切换浅色/深色主题。 | 查看页主题跟随系统主题变化，图表和文字仍可读。 |
| CD-V-18 | 直接打开不存在或已删除的大盘地址。 | 显示大盘不存在或不可访问状态，不进入死循环加载。 |

## 7. 编辑页测试

| 编号 | 操作 | 预期结果 |
|---|---|---|
| CD-E-01 | 创建者从列表或查看页进入编辑页。 | 页面展示标题、变量筛选区、网格画布、设置按钮和保存大盘按钮。 |
| CD-E-02 | 非创建者直接打开编辑页地址。 | 显示无编辑权限提示，并提供返回查看页入口。 |
| CD-E-03 | 点击「设置」。 | 打开大盘设置弹窗，可编辑名称、描述、可见范围和变量。 |
| CD-E-04 | 修改名称、描述后保存大盘。 | 保存成功提示「已保存」；返回列表后名称、描述同步更新。 |
| CD-E-05 | 将可见范围改为所有人、团队、私密。 | 对应选项可保存；团队可见时必须能选择团队。 |
| CD-E-06 | 新增内置资源变量。 | 可从「内置资源参数」分组选择变量，保存后查看页出现对应筛选项。 |
| CD-E-07 | 新增查询发现的 Label 变量。 | 配置组件查询后，下拉中出现「从查询发现的 Label」分组。 |
| CD-E-08 | 切换变量单选/多选。 | 保存后查看页变量选择模式与编辑配置一致。 |
| CD-E-09 | 删除未被查询引用的变量。 | 删除按钮可用，保存后变量从筛选区消失。 |
| CD-E-10 | 删除被查询引用的变量。 | 删除按钮禁用或给出被引用提示，不能误删。 |
| CD-E-11 | 空画布点击「新增组件」。 | 进入组件配置模式，展示预览区、查询配置区和右侧组件设置区。 |
| CD-E-12 | 配置组件名称、描述、图表类型。 | 预览标题和描述同步变化，图表类型可选折线图、面积图、柱状图、表格、指标卡、条形仪表。 |
| CD-E-13 | 查询模式选择「预置查询」。 | 可按图表类型选择兼容的预置查询，并填写必填参数。 |
| CD-E-14 | 查询模式选择「自定义查询」。 | 可编辑 PromQL / VictoriaMetrics 表达式。 |
| CD-E-15 | 在自定义查询中点击资源筛选提示。 | 系统插入对应 matcher，如服务、命名空间、pod、实例等筛选片段。 |
| CD-E-16 | 新增多个查询并隐藏其中一个查询。 | 隐藏查询不参与预览和保存后的执行；至少保留一个查询。 |
| CD-E-17 | 配置图例为自动或自定义。 | 自动图例使用返回标签生成名称；自定义图例支持 `$label` 或模板格式。 |
| CD-E-18 | 配置单位、小数位、自动换算和阈值。 | 预览中的数值格式、单位和阈值线或颜色符合配置。 |
| CD-E-19 | 点击「预览」。 | 使用当前数据组、时间范围、变量和查询配置刷新当前组件预览。 |
| CD-E-20 | 点击「保存面板」。 | 新组件加入大盘画布，页面标记为未保存大盘。 |
| CD-E-21 | 编辑已有组件后返回大盘。 | 未保存面板时弹出确认框，可继续编辑、放弃修改或保存后返回。 |
| CD-E-22 | 复制已有组件。 | 生成配置一致的新组件，标题带副本标识，并放入可用网格位置。 |
| CD-E-23 | 删除已有组件。 | 组件从画布移除，空出的网格位置可再次放置组件。 |
| CD-E-24 | 拖拽组件位置。 | 组件吸附到网格位置，避免互相覆盖，释放后布局稳定。 |
| CD-E-25 | 拖拽组件右下角调整尺寸。 | 组件尺寸变化后内容仍可读，不应遮挡标题、图例、坐标轴或表格。 |
| CD-E-26 | 点击「保存大盘」。 | 保存成功后未保存标识消失；刷新页面后配置仍保留。 |
| CD-E-27 | 模拟保存失败。 | 页面保留当前编辑内容，显示失败原因和重试入口。 |
| CD-E-28 | 有未保存大盘修改时离开页面。 | 弹出未保存提示，取消后留在编辑页，确认后才离开。 |

| 编号 | 操作 | 预期结果 |

## 10. 辅助接口核对

页面操作时可在浏览器 Network 中辅助核对以下接口是否按操作触发：

| 页面操作 | 相关接口 |
|---|---|
| 列表查询 | `GET /api/custom-dashboard/list` |
| 查看详情 | `GET /api/custom-dashboard/detail` |
| 新建大盘 | `POST /api/custom-dashboard/create` |
| 保存大盘 | `POST /api/custom-dashboard/update` |
| 复制大盘 | `POST /api/custom-dashboard/copy` |
| 删除大盘 | `DELETE /api/custom-dashboard/delete?id={id}` |
| 获取预置查询 | `GET /api/custom-dashboard/preset-queries` |
| 获取变量候选值 | `POST /api/custom-dashboard/variables/query` |
| 预览组件查询 | `POST /api/custom-dashboard/query/preview` |

## 11. 验收标准

1. P0 流程全部通过：列表打开、新建、查看、编辑保存、复制、删除、权限拦截。
2. 查询相关 P0 流程全部通过：数据组切换、时间范围切换、变量筛选、组件预览、查询异常重试。
3. 权限测试无越权查看、越权编辑和越权数据展示。
4. 常见桌面分辨率和浅色/深色主题下无影响使用的错位、遮挡和不可点击问题。
5. 主要页面操作无未捕获前端错误，失败状态有明确页面反馈。
