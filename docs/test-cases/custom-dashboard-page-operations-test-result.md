# 我的大盘页面操作测试结果

## 1. 测试结论

本次围绕「我的大盘」列表页、查看页、编辑页做了页面点击验证，并补充了两处已确认问题的修复与回归验证。

| 项目 | 结论 |
|---|---|
| 列表核心流程 | 通过：进入列表、搜索、查看、进入编辑、复制、删除取消、删除确认均已验证。 |
| 查看页核心流程 | 通过：查看页渲染、编辑入口、变量选择、时间范围切换、主题切换、已删除地址异常态均已验证。 |
| 编辑核心流程 | 通过：新建、设置名称/描述、变量模式切换、新增组件、自定义查询预览、保存面板、保存大盘已验证。 |
| 权限矩阵 | 部分覆盖：管理员创建者路径已验证；非创建者、无权限账号未验证。 |
| 兼容性 | 部分覆盖：列表页在 1366x768、1440x900、1920x1080 下无明显遮挡；查看/编辑页未逐项覆盖所有分辨率。 |

## 4. 问题复核与处理

| 编号 | 问题 | 复现 | 是否需要修复 | 修复方案与结果 |
|---|---|---|---|---|
| CD-BUG-01 | 创建者打开查看页会自动跳到编辑页 | 打开 `/custom-dashboard/{id}`，页面进入 `/edit` | 需要。创建者无法使用查看页，会影响查看页变量、时间范围、主题等操作测试和实际使用。 | 根因是查看页加载详情后对 `canEdit` 执行自动跳转。已修复为保留查看页渲染，只显示编辑按钮；补充前端行为测试覆盖该行为。 |
| CD-BUG-02 | 搜索无匹配关键字时仍返回可见大盘 | 搜索 `zzz-no-dashboard` 时仍显示 owned/team 大盘 | 需要。搜索结果不可信，会影响列表页查找和空态判断。 | 根因是后端列表查询把关键字条件和可见性 `OR` 条件拼接在同一查询链上，`OR owner_id = ?` 绕过关键字过滤。已修复为使用独立 DB 查询构造可见性条件，再与关键字条件组合；补充 DAO 回归测试。 |

## 5. 观察项

| 编号 | 现象 | 结论 |
|---|---|---|
| OBS-01 | 令牌过期时，部分接口先返回 `400 A0005 无效的token`，随后 `/api/user/refresh` 成功并自动重试原请求。 | 不阻塞流程，但会污染控制台错误计数；建议后续统一处理认证刷新前的控制台噪声。 |
| OBS-02 | 控制台存在 PostHog 未配置 token、React Router future flag、`findDOMNode`、AntD Modal/Menu deprecation 等警告。 | 属于既有开发环境/依赖警告，本次未纳入修复范围。 |
| OBS-03 | 测试中前端 Vite/后端进程曾重启，期间出现连接失败和 500。 | 判定为测试环境中断，不计入页面业务缺陷。 |

## 6. 未覆盖风险

1. 未使用非管理员账号验证「仅查看」「无创建」「无编辑」「无删除」权限。
2. 未完整验证团队可见、私密大盘对其他账号的列表和直达访问限制。
3. 未完整验证表格、指标卡、条形仪表、Top N、大量组件懒加载和拖拽缩放。
4. 未构造查询语法错误、超时、结果过大、无权限等异常查询场景。
5. 未做移动端或窄屏专项验证，本次只覆盖常见桌面宽度。

## 7. 回归建议

下次回归优先补齐：

1. 准备至少一个非管理员账号和一个无创建权限账号，执行权限矩阵。
2. 准备包含折线图、表格、指标卡、条形仪表和多组件布局的大盘，覆盖展示类型。
3. 构造异常查询和无数据查询，验证错误态、空态和重试入口。
4. 在清洁浏览器会话中记录控制台，仅保留当前流程新产生的错误。
