# 日志采集配置调整任务

## 设计边界

- 日志采集配置只提取用户需要填写的采集目标，并生成最终配置预览；其他探针配置仍保留原有编辑方式。
- 节点配置中的“日志采集”只管理当前节点的宿主机文件采集，主要字段为路径、目录深度和文件匹配名。
- 集群和批量配置中的“日志采集”管理容器标准输出采集；用户按需添加过滤器，未添加的过滤器不生成配置字段。
- Namespace、Pod、Container、Pod 标签、环境变量和容器标签过滤器平级展示；非 K8s 集群不展示 K8s 专属过滤器。
- iLogtail 的解析、Tag、缓冲等非筛选参数默认收在“高级配置”中。
- 节点继承所属集群的容器采集规则，并可追加当前节点的宿主机文件规则；节点页只读展示集群规则并提供直达集群日志采集配置的入口。
- 节点页将集群继承摘要置于最前并使用信息色底色区分；下方“生效规则”列表统一展示集群继承规则和当前节点规则，每条规则明确标注来源。
- 日志采集不要求用户填写规则名称，内部标识由系统生成。
- 当前保存的是日志采集管理记录和可预览的 iLogtail 输入文件；在完整发布链路确认前，页面不声称配置已经下发到探针。
